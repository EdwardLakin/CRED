# CRED Report Review Workspace

The report review workspace is the server-rendered route at `app/dashboard/sessions/[id]/report/page.tsx`. It keeps the existing session data loading, AI draft actions, review gate, delivery actions, share-link controls, and report activity queries in the page while rendering the UI through smaller local server components:

- `ReportOverview`
- `PrintableReportPreview`
- `AiDraftReview`
- `ReportSidebar`
- `DeliveryCenter`
- `ReportActivity`

## Printable report language

The workspace should describe the output as a **Printable Report** or **Save Report** flow unless CRED adds a true binary PDF response. The current report route returns printable HTML, so buttons and guidance should avoid implying that a binary PDF file is generated by the app.

## Preview behavior

The embedded preview iframe must use the report route with `?preview=1`. The report route treats `preview=1` as preview-only and must not insert `exports` rows or record `printable_report_opened` usage events for the embedded preview.

Authenticated full-report opens remain delivery/export behavior and continue to be gated by the ready-for-delivery review status.
